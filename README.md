# FAERS disproportionality analysis: bispecific antibodies versus CAR T-cell therapy in multiple myeloma

Analysis code for the study:

> **Comparative Safety of Bispecific Antibodies versus CAR T-Cell Therapy in Multiple Myeloma: A Disproportionality Analysis of the US FDA Adverse Event Reporting System (FAERS)**
> Xuan Zhou\*, Min Tan\*, Xiaojuan Zhang\*, Faqin Lv†, Lixun Guan†
> \* co-first authors · † co-corresponding authors

This repository contains the complete, reproducible analysis pipeline underlying the manuscript. It downloads the public FDA FAERS quarterly data files, de-duplicates and merges them, identifies drug exposures and adverse events, computes reporting odds ratios (RORs), performs head-to-head class comparisons, models time-to-onset, and runs all sensitivity analyses.

---

## 1. Data source

All input data are **publicly available and de-identified**. The FAERS quarterly ASCII data files (2021 Q1 – 2026 Q2, 22 quarters) are distributed by the US Food and Drug Administration. This repository does **not** redistribute them; `src/01_download.py` retrieves them directly from the FDA.

## 2. Requirements

- Python 3.12
- pandas, numpy, scipy, matplotlib, requests (see `requirements.txt`)

```bash
pip install -r requirements.txt
```

## 3. Pipeline

Run the scripts in order from the project root:

| Step | Script | Purpose | Key outputs |
|---|---|---|---|
| 1 | `src/01_download.py` | Download FAERS quarterly ZIP archives | `data/raw/*.zip` |
| 2 | `src/02_clean.py` | Parse the six tables per quarter; de-duplicate on `PRIMARYID` keeping the most recent `FDA_DT`; merge | `data/processed/*.csv` |
| 3 | `src/03_build_dataset.py` | Map drug names (primary suspect only) and MedDRA Preferred Terms; build exposure and event-hit datasets | `exposure.csv`, `event_hits.csv`, `analysis_dataset.csv` |
| 4 | `src/04_ror_analysis.py` | Reporting odds ratios with 95% CI; head-to-head chi-square comparison; forest plot | `table1_baseline.csv`, `table2_ror_matrix.csv`, `table3_headtohead.csv`, `figure2_forest.png` |
| 5 | `src/05_tto_analysis.py` | Time-to-onset (median, IQR) and two-parameter Weibull shape with bootstrap CI | `table4_tto.csv`, `figure3_tto.png` |
| 6 | `src/06_sensitivity.py` | Three pre-specified sensitivity analyses (S1 myeloma indication; S2 exclusion of co-reported non-primary-suspect roles; S3 report-year strata) | `suppl_table2_sensitivity.csv` |

Example:

```bash
python src/01_download.py
python src/02_clean.py
python src/03_build_dataset.py
python src/04_ror_analysis.py
python src/05_tto_analysis.py
python src/06_sensitivity.py
```

## 4. Configuration

| File | Contents |
|---|---|
| `config/drug_mapping.py` | Generic names, brand names and spelling variants for the five study drugs; group assignment (BsAb vs CAR-T) |
| `config/event_definitions.py` | MedDRA Preferred Term lists defining each of the eight event categories plus the fatal-outcome definition (`OUTC_COD = "DE"`) |

Editing these two files is the only place where study definitions are set; every downstream statistic derives from them.

## 5. Analysis definitions (summary)

- **Exposure**: any report with a study drug as primary suspect (`ROLE_COD = "PS"`), counted at the case level (`PRIMARYID`).
- **Background comparator**: all other drugs reported to FAERS over the same 22-quarter window.
- **Measure**: ROR = (a/c)/(b/d), 95% CI by the logarithmic method; 0.5 added to all cells if any cell is zero.
- **Signal (SDPR)**: lower 95% CI bound > 1 **and** a >= 3.
- **Between-group comparison**: chi-square test with Yates continuity correction on the proportion of cases with each outcome.
- **Time-to-onset**: event date minus the earliest therapy start date, restricted to 0-1095 days; two-parameter Weibull fit by maximum likelihood with a bootstrap 95% CI for the shape parameter beta (beta < 1 early-failure, approximately 1 random, > 1 wear-out).

## 6. Outputs

All tables and figures in the manuscript are generated by steps 4-6 and written to `output/`. Because the derived tables are fully reproducible from the public source data, they are not version-controlled in this repository.

## 7. Reporting standard

The analysis and manuscript follow the **READUS-PV** reporting guideline for disproportionality analyses (Fusaroli et al., Drug Saf 2024), and, where applicable, the **STROBE** statement.
